Developer: Juner Punzal

Technologies: Vue 3, Vite, Tailwind CSS, Local Storage

1. System Overview

The Attendance Monitoring System is a single-page web application that helps an administrator register students, record daily attendance, monitor current attendance statistics, and review individual attendance performance. The application is responsive, uses a consistent dashboard layout, and preserves data in the browser using local storage.

2. Architecture and Vue Implementation

The system is organized into reusable Vue components. App.vue controls page navigation, settings, dashboard totals, and reports. Feature-specific interface components such as Students.vue and Attendance.vue communicate through props and emitted events. Shared business logic is contained in composables, keeping the interface separate from data operations.

AreaImplementation
ReactivityVue ref and computed state automatically update lists, totals, searches, filters, and reports.
Component communicationParent-to-child props and child-to-parent events support navigation, forms, confirmation dialogs, and notifications.
PersistenceStudents, attendance records, system details, and dark-mode preference are saved in browser local storage.
NavigationSidebar, dashboard quick actions, header actions, and hash URLs such as /#attendance provide predictable navigation.

5. Running and Building the Project

Install dependencies with npm install. Start development mode with npm run dev. Create an optimized production build with npm run build. The production build completed successfully during verification.

6. Version Control and Submission

The project is initialized as a Git repository with a descriptive initial commit. It is ready to be connected to a public GitHub repository. The submission package excludes node_modules, generated build output, and Git metadata so it is clean and easy to submit.
